# Wallflow

Минималистичный рабочий стол для Windows 10/11 в одном лёгком приложении (C# / WPF, .NET 8, без браузерного движка):

- **Обои из открытых источников по API**: Wallhaven (HD → 8K) и Bing (обои дня в 4K). Внутрь приложения ничего не зашито.
  Фильтры: разрешение «не меньше» / точное (Full HD, **2K 2560×1440**, UW-QHD, 4K, 5K, 8K, «под мой экран»), соотношение сторон,
  цвет, категории, сортировка (топ за период, новые, популярные, случайно), теги `#tag`, похожие `like:id`. Избранное, слайдшоу.
- **Папки как на iPhone**: ярлыки с рабочего стола сами раскладываются по стеклянным папкам (Игры, Браузеры, Общение, Медиа,
  Творчество, Разработка, Офис, Утилиты). Клик открывает папку, правый клик позволяет переименовать или перенести ярлык.
  Новые ярлыки сами попадают в нужную папку. Обычные значки можно скрыть одной галочкой. Файлы ярлыков не трогаются.
- **Виджеты на стекле**: часы с днём недели (*SUNDAY*) в 9 стилях со шрифтами Bebas Neue, Great Vibes, Orbitron, Unbounded,
  Monoton и другими; погода (Open-Meteo, без ключа) с прогнозом на 5 дней; календарь месяца.
- **Ещё виджеты**: плеер (то, что сейчас играет в любом приложении: Spotify, браузер, Яндекс Музыка…; пауза/перемотка),
  заметки (сколько угодно, цветные), список дел.
- **Часы**: 15 стилей, любой цвет через палитру, градиент (свой или готовый), 12/24 ч, секунды без дёрганья.
- **Стеклянный док вместо панели задач**: Пуск, поиск, закреплённые программы (берутся с твоей панели задач), открытые окна,
  часы. Обычная панель прячется, окна не заходят под док, в полноэкранных играх док исчезает. Настройки обычной панели:
  поиск, «Представление задач», виджеты Windows, выравнивание.
- **Живые обои**: вкладка в галерее — NASA (без ключа), Pexels и Pixabay (бесплатный ключ), фильтры по разрешению и ориентации,
  превью видео; свой видеофайл. Пауза, когда окно на весь экран. Кадр из видео становится обычными обоями (для стекла).
- **Трей и автозапуск**: при входе в Windows стартует сразу в трей.

## Скачать
Вкладка **Actions** → последний зелёный запуск **Build Windows** → артефакт **Wallflow-windows-x64**:

| Файл | Что это |
|---|---|
| `Wallflow.exe` | Всё внутри, ничего ставить не нужно, самый быстрый запуск (~220 МБ) |
| `Wallflow-compact.exe` | То же, но сжатый (~70 МБ), стартует на секунду дольше |
| `Wallflow-lite.exe` | Маленький файл, нужен [.NET 8 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/8.0) |

Положи exe в постоянную папку (например `C:\Program Files\Wallflow` или `Documents\Wallflow`) и запусти.
Автозапуск запомнит именно это место.

## Управление
- **Значок в трее**: обои, следующие обои, слайдшоу, «✎ Переставить виджеты» (перетащи мышкой, потом сними галочку),
  какие виджеты показывать, скрыть значки, настройки, выход.
- При выходе обычные значки рабочего стола возвращаются.

## Потребление
Один процесс. Галерея и окно настроек существуют только пока открыты, после закрытия память возвращается системе.
Часы просыпаются раз в минуту, погода обновляется раз в 30 минут, календарь в полночь. В простое процессор ≈ 0%.
Для минимума можно выключить «Размытие фона» в настройках стекла.

## Сборка
```
dotnet publish src/Wallflow/Wallflow.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true
```

Настройки и лог ошибок хранятся в `%AppData%\Wallflow`.
